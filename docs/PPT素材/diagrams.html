图表 2：全文检索全链路业务请求时序图 对应 Slide 4 / 5 
sequenceDiagram
    autonumber
    actor User as 前端用户 (Vue3)
    participant GW as 微服务网关 (18081)
    participant Auth as 权限过滤器 (Security)
    participant SC as 检索控制器 (18082)
    participant SS as 检索业务服务 (SearchService)
    participant Seg as 分词组件 (Jieba)
    participant Mongo as MongoDB 数据库 (search_document)
    participant Alg as 动态切片与高亮处理

    User->>GW: POST /admin-api/search/document/page (关键词, 检索模式)
    GW->>Auth: 校验 Token 与 SpEL 权限
    Auth-->>GW: 鉴权通过
    GW->>SC: 路由分发 (基于 Path 前缀与负载均衡)
    SC->>SS: 调用 pageSearchDocuments(ReqVO)
    alt 全库分词检索模式 (all)
        SS->>Seg: segment(searchKey) 执行细粒度切词
        Seg-->>SS: 返回空格拼接分词串
        SS->>Mongo: 执行 TextQuery ($text 复合倒排索引)
        Mongo-->>SS: 返回匹配文档列表 + $textScore 相关度得分
    else 精准匹配模式 (title / content)
        SS->>Mongo: 构造 Criteria.regex 执行正则模糊匹配
        Mongo-->>SS: 返回按时间倒序排列的精准匹配文档列表
    end
    SS->>Alg: 触发正文动态切片 (getSnippet) 与长词降序高亮 (highlightText)
    Alg-->>SS: 返回带 mark 标签与省略号的高亮阅读片段
    SS-->>SC: 组装 PageResult 返回分页结果
    SC-->>GW: 封装统一通用返回对象 (CommonResult)
    GW-->>User: 响应 JSON 数据并在前端列表与研判阅读器渲染
